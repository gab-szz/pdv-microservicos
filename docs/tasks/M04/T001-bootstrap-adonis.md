# T001 — Inicializar o PDV como AdonisJS

> **Milestone:** M04 · **Status:** pendente · **Depende de:** M03

## Objetivo
Substituir o bootstrap Fastify do PDV pelo esqueleto oficial do AdonisJS, preservando-o como workspace pnpm.

## Arquivos
`pdv-microservico/`, `pnpm-workspace.yaml`, `package.json`

## Pronto quando
- O PDV contém estrutura padrão do AdonisJS e scripts compatíveis com pnpm.
- `pnpm --filter pdv-microservico dev` inicia a aplicação.

## Verifica
`pnpm --filter pdv-microservico dev`
